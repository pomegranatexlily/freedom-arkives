# Security policy

## Reporting security concerns responsibly

**GitHub issues are public.** Never post an exploit, access token, private code, personal data, or other sensitive details in an issue, pull request, or repository discussion.

For a security vulnerability, open the repository **Security** tab and look for **Report a vulnerability**. If private vulnerability reporting is enabled, use that channel. If it is not available, **do not disclose exploit details publicly**. The maintainers must configure a private security contact channel before accepting private reports.

For general, non-sensitive questions or ordinary bugs, use the structured [GitHub issue forms](https://github.com/pomegranatexlily/freedom-arkives/issues/new/choose). These are PUBLIC and are not suitable for personal-data access or deletion requests.

## Data practices and restrictions

- This repository currently has no account registration or paid subscriptions.
- Do not put passwords, financial records, API credentials, or sensitive personal documents in browser-saved workspaces.
- GitHub Pages projects under the same `pomegranatexlily.github.io` hostname share browser-origin storage; project paths are not a security boundary.
- Do not share screenshots containing private data while reporting bugs.
- This project does not promise absolute security or legal compliance.

Read [the project privacy policy](https://pomegranatexlily.github.io/freedom-arkives/privacy.html) for the current data inventory and further information.

## Maintainer actions before collecting private personal information

- [ ] Configure and verify a dedicated **private** business privacy contact inbox or a secure privacy request portal, and publish that verified address/channel in the privacy policy.
- [ ] Verify/enable GitHub private vulnerability reporting if supported for the repository.
- [ ] Move user-account or sensitive-data features to distinct origins, separate from other GitHub Pages apps.
- [ ] Test data deletion, consent enforcement, and browser network behavior; request legal/privacy review.
