# Support & privacy questions

This project's GitHub issue tracker **already exists**. The [issue forms](.github/ISSUE_TEMPLATE) let visitors report public bugs and ask general questions. **All issue posts and comments are public**, so do not use them to disclose personal data.

- **Public, non-sensitive product bug:** choose the Bug report form.
- **Public, general privacy question:** choose Privacy question (public).
- **Sensitive privacy request, access/deletion request, or security vulnerability:** **do not create a public issue**. A dedicated, verified private contact channel is not yet published; the maintainer must configure one before receiving sensitive requests. Vulnerabilities may be submitted using the repository's **Report a vulnerability** feature only if GitHub shows that option.

The privacy policy is available at https://pomegranatexlily.github.io/freedom-arkives/privacy.html. The [privacy audit](PRIVACY-AUDIT.md) describes residual risks that must be addressed before account registration or subscriptions.
